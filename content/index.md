Accessible CSS in **under 8&nbsp;KB gzipped**. WCAG&nbsp;2.2 ready.
Cascade-layered. Zero JavaScript. Drop into any page.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@1.1.7
```

skeletonic.io
=============

[![Codacy Badge](https://api.codacy.com/project/badge/Grade/7df45f6a0c3b49d283ef64d9944ab7ce)](https://app.codacy.com/gh/sebastienrousseau/skeletonic.io?utm_source=github.com&utm_medium=referral&utm_content=sebastienrousseau/skeletonic.io&utm_campaign=Badge_Grade_Settings)

Source for **<https://skeletonic.io>** — the home page of
[Skeletonic Stylus](https://github.com/sebastienrousseau/skeletonic-stylus)
v1.1.7.

The site is generated by **[Shokunin SSG](https://github.com/sebastienrousseau/shokunin)
v0.0.34** (a content-first Rust static site generator) and styled with
**Skeletonic Stylus itself** — no Bootstrap, no Tailwind, no other
framework.

## Build &amp; preview locally

You'll need the **`ssg`** binary from
[Shokunin v0.0.34](https://github.com/sebastienrousseau/shokunin):

```bash
# install once
cargo install --git https://github.com/sebastienrousseau/shokunin --tag v0.0.34 ssg

# build
ssg --config config.toml

# build + watch + serve at http://127.0.0.1:8000
ssg --config config.toml --watch
```

The build output lands in `docs/`, which is what GitHub Pages serves.

## Edit content

Each page is a markdown file under `content/` with a YAML front-matter
block. The minimum required fields are:

```yaml
---
title: "Page title"
description: "Meta description shown in search results."
layout: page          # → templates/tera/page.html
permalink: /slug/
date: 2026-04-08
author: Sebastien Rousseau
theme_color: "hsl(210, 100%, 42%)"
---
```

`layout` selects the Tera template; `theme_color` is bridged to a
`--theme-color` CSS custom property by `base.html`.

## Deploy

GitHub Pages serves directly from `main` / `/docs`. The
`.github/workflows/build-site.yml` workflow:

1. Installs the `ssg` binary
2. Runs `ssg --config config.toml`
3. Verifies no foreign CSS framework leaked into the build
4. Commits the regenerated `docs/` back to `main`

## CSS philosophy

The site loads exactly **two** stylesheets on every page (plus a third
on `/animations/` only):

| Stylesheet | Loaded where | Purpose |
|---|---|---|
| `/css/skeletonic.min.css` | every page | core (cascade-layered, WCAG 2.2) |
| `/css/skeletonic-tachyons.min.css` | every page | utility / palette helpers |
| `/css/skeletonic-animations.min.css` | `/animations/` only | optional motion module |

All three files are copies of the v1.1.7 build artefacts shipped by
the [skeletonic-stylus](https://github.com/sebastienrousseau/skeletonic-stylus)
library; they're version-pinned and integrity-hashed (`sha384`) in
`templates/tera/base.html`.

The only inline `<style>` block in the entire site is a small one in
`base.html` containing the `--theme-color` bridge, the golden-ratio
hero overrides, the sticky header rules, and the WCAG 2.2 skip-link.

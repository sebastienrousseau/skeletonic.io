Ni ṣoki

Skeletonic Stylus jẹ ile-ikawe CSS Stylus orisun-ṣiṣi fun aṣa UI ti a le wọle si, ti o yara, ti o ni modulu.

A bi i ni ọdun 2018 gẹgẹbi idanwo ti ara ẹni ninu fifiranṣẹ CSS ti o kere laisi fifun awọn ọna iṣẹ ti ile-ikawe paati gidi silẹ. Lẹhin ọdun mẹjọ, ibi-afẹde naa ko yipada.

Ohun ti o fun ọ

Iyara bi manamana

Ṣe apẹrẹ ati ṣe aṣa awọn atọwọdọwọ ti o dahun ni awọn iṣẹju diẹ. Awọn oniyipada CSS abinibi, awọn kilasi ti a ti ṣeto tẹlẹ, grid ọwọn-12 ti o bo gbogbo ẹya HTML ti itumọ.

Fẹẹrẹfẹ

8.6 KB gzipped. Awọn oju-iwe gba ni iyara ju. Gbogbo bulọọki ikọle pataki wa ninu.

Apẹrẹ ti o dahun

Ti a ṣe fun kọmputa ati alagbeka. Awọn eto mu ara wọn bamu si ẹrọ eyikeyi. Ti o dara fun ifọwọkan, HTML ti itumọ jakejado.

Irayẹ-si

WCAG 2.2 ti a fi sinu: awọn oruka focus-visible, iyatọ AA, awọn oluranlọwọ skip-link, awọn paati ti o rọrun fun itẹwe, atilẹyin idinku-iṣipopada — ko si iwe-aṣa afikun, ko si aria-* boilerplate.

Ile-ikawe paati

Awọn paati CSS modulu ati awọn adalu Stylus. Awọn bọtini, awọn fọọmu, awọn kaadi, awọn itaniji, awọn aami, awọn palẹti ati awọn ere idasọnu — mimọ, modulu, ti setan lati fi sii.

Ọfẹ & orisun-ṣiṣi

Ti Sebastien Rousseau ṣe apẹrẹ, kọ, ati ṣe itọju. Ti a fun ni iwe-aṣẹ meji labẹ MIT tabi Apache 2.0. Ko si owo, ko si idiyele iwe-aṣẹ, paapaa fun lilo iṣowo.

Bawo ni o ṣe fi wewe

Iwe-aṣa ti ara ẹni kan bo iwe-kikọ, awọn bọtini, awọn fọọmu, awọn kaadi, awọn tabili, awọn palẹti, awọn ere idasọnu ati awọn kilasi iwulo. JavaScript kankan ko si. Ko si igbesẹ ikọ ti a beere. Ko si awọn igbarale ẹlẹgbẹ lori Bootstrap, Tailwind tabi Bulma.

Awọn ilana

  1. Irayẹ-si ni ipilẹ, kii ṣe oke. Ibamu WCAG 2.2 ti a fi sinu gbogbo paati, a ko fi kun lẹhin bi "aṣa" kan.
  2. Awọn baiti ṣe pataki. Iwe-aṣa kan ti a firanṣẹ ko yẹ ki o bọ isuna iwuwo oju-iwe rẹ. Opin 8 KB gzipped ni a fi ipa mu ninu CI.
  3. Awọn ipele cascade bori ogun specificity. Ṣe atunṣe ohunkohun pẹlu igboya — ko si !important, ko si awọn ẹtan aṣẹ-DOM.
  4. Stylus si dara. Kukuru, ifarahan, o si jẹ ki ile-ikawe wa ninu ~3,000 awọn ila ti a le ka.
  5. Aibikita jẹ ẹya. Ko si awọn igbarale JS. Ko si idan akoko-ikọ. Ko si awọn iyipada orukọ ti o fọ. Awọn kilasi CSS ti o ṣe ohun ti wọn sọ gangan.
  6. Ti a le ṣe aṣa ni iṣẹju-aaya. Awọn ohun-ini aṣa CSS abinibi fun awọn awọ, aaye, iru ati radii.
  7. Ẹwọn-ipese ti a fi okun mu. Ẹri npm ti a fọwọsi. Awọn imudojuiwọn Dependabot ti a fi idi mulẹ. CVE-2023-44270 ti a ṣe atunṣe nipasẹ overrides.

<li><strong><code>$primary</code> 加深</strong>至 <code>hsl(210, 100%, 42%)</code>，满足按钮/徽章/链接中白色文本的 AA 对比度。</li> <li><strong><code>$secondary</code> 加深</strong>至 <code>hsl(195, 100%, 33%)</code>。</li> <ul> <li><strong>级联层</strong> — 每个块现在都位于 <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code> 中。</li> <li><strong>CycloneDX SBOM</strong> 作为 npm 压缩包的一部分生成。</li> <li><strong><code>size-limit</code> 预算</strong> 在 CI 中强制执行：核心样式表 8 KB gzip 上限。</li> <li><strong>CVE-2023-44270</strong>（postcss 换行）通过 <code>pnpm.overrides</code> 修补。</li> <li>npm 发布工作流启用来源验证与签名（<code>--provenance --access public</code>）。</li> <li>从代码检查配置中移除已归档的 <code>stylelint-a11y</code> 插件。</li> </ul> <h3>仓库整理与消费者包</h3> <ul> <li>移除遗留 <code>package/</code>

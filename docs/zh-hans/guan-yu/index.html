<h2>简短介绍</h2> <p><strong>Skeletonic Stylus</strong> 是一个开源 <a href="https://stylus-lang.com">Stylus</a> CSS 库，用于无障碍、高性能、模块化的 UI 样式开发。</p> <p>它诞生于 2018 年，最初是一个<strong>精简 CSS 体积</strong>的个人实验，同时保留了完整组件库的开发体验。八年过去，目标始终未变。</p> <h2>核心能力</h2> <div class="feature-grid"> <article class="feature-card"> <img class="feature-icon" src="/images/icons/thunder.min.svg" alt="闪电" width="64" height="64" loading="lazy" decoding="async"> <h3>极速开发</h3> <p>几分钟即可设计和定制响应式界面。原生 CSS 变量、预定义类名、覆盖所有语义 HTML 元素的 12 列栅格。</p> </article> <article class="feature-card"> <img class="feature-icon" src="/images/icons/lightweight.min.svg" alt="羽毛" width="64" height="64" loading="lazy" decoding="async"> <h3>轻量小巧</h3> <p>gzip 后约 7.7 KB。页面加载更快，核心构建块一个不少。</p> </article> <article class="feature-card"> 上限在 CI 中强制执行。</li> <li><strong>级联层胜过优先级大战。</strong> 放心覆盖任何样式——无需 <code>!important</code>，无需 DOM 顺序技巧。</li> <li><strong>Stylus 依然优秀。</strong> 简洁、表达力强，让整个库保持在约 3,000 行可读代码。</li> <li><strong>平实即特性。</strong> 无 JS 依赖。无构建时魔法。无破坏性重命名。CSS 类名名副其实。</li> <li><strong>秒级主题定制。</strong> 原生 CSS 自定义属性控制颜色、间距、字体和圆角。</li> <li><strong>供应链加固。</strong> 签名的 npm 来源验证。Dependabot 锁定更新。CVE-2023-44270 已通过覆盖修补。</li> </ol> <h2>版本管理与语义化版本</h2> <p>Skeletonic Stylus 遵循 <a href="https://semver.org">语义化版本 2.0</a>。</p> <table> <thead> <tr> <th>升级类型</th> <th>时机</th> <th>示例</th> </tr> </thead> <tbody> <tr>

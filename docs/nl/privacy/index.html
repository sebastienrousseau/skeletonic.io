Geen verzoek dat je doet wordt geregistreerd buiten de standaard GitHub Pages-toegangslogboeken.</p> </blockquote> <hr class="hr-text" data-content="Details"> <h2>Welke gegevens worden verzameld</h2> <ol> <li><strong>GitHub Pages-toegangslogboeken.</strong> Wanneer je een pagina laadt, registreert GitHub je IP-adres, de verzoek-URL en het tijdstip. Het privacybeleid van GitHub is van toepassing — zie <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">docs.github.com/en/site-policy</a>.</li> <li><strong>Het contactformulier.</strong> Als je het formulier op <code>/nl/contact/</code> verstuurt, gaan de gegevens via <a href="https://formspree.io">Formspree</a>, dat ze doorstuurt naar het e-mailadres van de beheerder. Het privacybeleid van Formspree is van toepassing.</li> <li><strong>Service worker.</strong> Het <code>sw.js</code>-script slaat HTML-, CSS-, JS- en afbeeldingsresponsen <strong>lokaal op in je browser</strong> zodat de site offline werkt. Er wordt niets naar elders verstuurd.</li> </ol> <h2>Wat wordt <em>niet</em> verzameld</h2> <ul> <li>Google Analytics, Plausible, Fathom, of enige andere analysetag.</li> <li>Cookies van welke aard dan ook. De site plaatst er geen.</li> <li>Local storage of IndexedDB buiten de service-worker-cache.</li> <li>Fingerprinting, advertentienetwerken of trackers van derden.</li> </ul> <h2>Je rechten</h2> <p>Als je het contactformulier hebt gebruikt en je bericht wilt laten verwijderen, stuur dan een e-mail vanaf het adres waarmee je het hebt verstuurd en ik zal het binnen 30 dagen wissen.</p> <p><a href="/nl/voorwaarden/">Lees de voorwaarden →</a> · <a href="/nl/contact/">Neem contact op →</a></p> </div>

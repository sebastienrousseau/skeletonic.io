<h2>원칙</h2> <ol> <li><strong>접근성은 기본이지 옵션이 아닙니다.</strong> WCAG 2.2 준수가 모든 구성 요소에 내장되어 있으며, "테마"로 추가되는 것이 아닙니다.</li> <li><strong>바이트가 중요합니다.</strong> 단일 스타일시트가 페이지 용량 예산을 초과해서는 안 됩니다. 8 KB gzipped 상한선이 CI에서 강제됩니다.</li> <li><strong>캐스케이드 레이어가 명시도 전쟁을 이깁니다.</strong> <code>!important</code> 없이, DOM 순서 트릭 없이 자신 있게 오버라이드할 수 있습니다.</li> <li><strong>Stylus는 여전히 훌륭합니다.</strong> 간결하고 표현력이 풍부하며, 라이브러리를 약 3,000줄의 읽기 쉬운 코드로 유지할 수 있습니다.</li> <li><strong>단조로움은 기능입니다.</strong> JS 종속성 없음. 빌드 시 마법 없음. 호환성 깨는 이름 변경 없음. CSS 클래스는 이름 그대로 동작합니다.</li> <li><strong>몇 초 만에 테마 적용 가능.</strong> 색상, 간격, 타이포그래피, 둥글기를 위한 네이티브 CSS 커스텀 속성을 지원합니다.</li> <li><strong>공급망이 강화되었습니다.</strong> 서명된 npm 출처 증명. 고정된 Dependabot 업데이트. CVE-2023-44270이 overrides를 통해 패치되었습니다.</li> </ol> <h2>버전 관리 & 시맨틱 버전</h2> <p>Skeletonic Stylus는 <a href="https://semver.org">Semantic Versioning 2.0</a>을 따릅니다.</p> <table> <thead> <tr> <th>범위</th> <th>시기</th> <th>예시</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">공개 클래스, 믹스인 또는 토큰의 제거 또는 이름 변경</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">새로운 구성 요소, 믹스인 또는 토큰 추가</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">버그 수정, 접근성 개선, 성능, 보안</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>모든 공개 클래스 이름, 모든 CSS 커스텀 속성 및 모든 내보내진 Stylus 믹스인은 공개 API의 일부입니다. 호환성을 깨는 변경 사항은 메이저 버전 업데이트와 마이그레이션 가이드를 동반합니다.</p> <h2>관리</h2> <p>Skeletonic Stylus는 <a href="https://sebastienrousseau.com">Sebastien Rousseau</a>가 설계, 개발 및 유지관리합니다. <a href="https://opensource.org/licenses/MIT">MIT</a> 및 <a href="https://opensource.org/licenses/Apache-2.0">Apache 2.0</a> 이중 라이선스입니다.</p> <p>이슈, 아이디어 및 기여를 환영합니다 — <a href="/ko/giyeo/">기여 가이드를 확인하십시오</a>.</p> </div>

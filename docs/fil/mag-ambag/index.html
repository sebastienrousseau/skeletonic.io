Lahat ng commit ay nilalagdaan.</li> <li><strong>Stylus:</strong> 4-space na indent, walang semicolon, mas pinipili ang <code>$variables</code> kaysa sa mga magic number, bawat public class ay nasa isang cascade layer.</li> <li><strong>Aksesibilidad:</strong> anumang bagong component ay dapat malinaw na nakakatugon sa WCAG 2.2 AA; patakbuhin ang <code>node scripts/a11y-test.mjs</code> laban sa showcase bago magbukas ng PR.</li> <li><strong>Size budget:</strong> ang core stylesheet ay dapat manatili sa ilalim ng <strong>8 KB gzipped</strong>. Kung itutulak ito ng iyong pagbabago, bigyang-katwiran ito sa PR.</li> </ul> <hr class="hr-text" data-content="Mga Pull request"> <h2>Mga Pull request</h2> <ol> <li>Magbukas muna ng isyu para sa anumang hindi trivial — nakakatipid ng muling paggawa.</li> <li>Panatilihing nakatutok ang mga PR: isang lohikal na pagbabago bawat PR.</li> <li>I-update ang <code>CHANGELOG.md</code> sa ilalim ng "Unreleased".</li> <li>Tiyaking berde ang CI bago humiling ng review.</li> <li>Squash-merge ang default; lilinisin ang mga commit message sa merge.</li> </ol> <hr class="hr-text" data-content="Code of conduct"> <h2>Code of conduct</h2> <p>Sa pamamagitan ng paglahok, sumasang-ayon ka na sumunod sa <a href="https://www.contributor-covenant.org/version/2/1/code_of_conduct/">Contributor Covenant 2.1</a>.

sa WCAG 2.2 ay kasama na sa bawat component, hindi ibinubolt-on bilang isang "theme".</li> <li><strong>Mahalaga ang bawat byte.</strong> Ang isang shipped na stylesheet ay hindi dapat sumira sa iyong page-weight budget. Ang 8 KB gzipped na limitasyon ay ipinatutupad sa CI.</li> <li><strong>Ang cascade layer ay mas mabuti kaysa sa specificity war.</strong> Mag-override ng kahit ano nang may kumpiyansa — walang <code>!important</code>, walang DOM-order na trick.</li> <li><strong>Maganda pa rin ang Stylus.</strong> Maikli, expressive, at pinapanatili ang library sa ~3,000 nababasang linya.</li> <li><strong>Ang boring ay isang tampok.</strong> Walang JS dependency. Walang build-time magic. Walang breaking rename. CSS class na ginagawa nang eksakto ang sinasabi nila.</li> <li><strong>Ma-theme sa ilang segundo.</strong> Mga native CSS custom property para sa kulay, spacing, type at radii.</li> <li><strong>Supply-chain hardened.</strong> Signed npm provenance. Naka-pin na Dependabot update. CVE-2023-44270 patched sa pamamagitan ng override.</li> </ol> <h2>Versioning & semver</h2> <p>Ang Skeletonic Stylus ay sumusunod sa <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Bump</th> <th>Kailan</th> <th>Halimbawa</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Pag-alis o pag-rename ng isang public class, mixin, o token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Pagdagdag ng bagong component, mixin, o token</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Pag-aayos ng bug, a11y polish, performance, seguridad</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Lahat ng public class name, lahat ng CSS custom property, at lahat ng exported Stylus mixin ay bahagi ng public API.

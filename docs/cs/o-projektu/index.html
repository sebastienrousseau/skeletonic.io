<li><strong>Na bajtech zalezi.</strong> Jeden dodavany stylesheet by nemel vybuchnout vas rozpocet na velikost stranky. Strop 8 KB gzipped je vynucovan v CI.</li> <li><strong>Kaskadove vrstvy porazily valky o specificitu.</strong> Cokoli prepiste s jistotou — zadne <code>!important</code>, zadne triky s poradim v DOM.</li> <li><strong>Stylus je stale skvely.</strong> Strucny, expresivni a umoznuje knihovne zustat v ~3 000 citelnych radcich.</li> <li><strong>Nuda je vlastnost.</strong> Zadne JS zavislosti. Zadna build magie. Zadne lamic prejmenovani. CSS tridy, ktere delaji presne to, co rikaji.</li> <li><strong>Tema za par sekund.</strong> Nativni CSS vlastni vlastnosti pro barvy, odsazeni, typografii a zaobleni.</li> <li><strong>Zabezpeceny dodavatelsky retezec.</strong> Podepsany npm provenance. Fixovane Dependabot aktualizace. CVE-2023-44270 opraveno pres overrides.</li> </ol> <h2>Verzovani & semver</h2> <p>Skeletonic Stylus se ridi <a href="https://semver.org">Semantickym verzovanim 2.0</a>.</p> <table> <thead> <tr> <th>Zmena</th> <th>Kdy</th> <th>Priklad</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Odstraneni nebo prejmenovani verejne tridy, mixinu nebo tokenu</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Pridani nove komponenty, mixinu nebo tokenu</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Opravy chyb, vylepseni pristupnosti, vykon, bezpecnost</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Vsechny verejne nazvy trid, vsechny CSS vlastni vlastnosti a vsechny exportovane Stylus mixiny jsou soucasti verejneho API.

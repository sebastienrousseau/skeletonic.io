nie dokladana jako „motyw".</li> <li><strong>Kazdy bajt ma znaczenie.</strong> Pojedynczy dostarczony arkusz stylow nie powinien przekraczac budzetu rozmiaru strony. Limit 8 KB gzipped jest egzekwowany w CI.</li> <li><strong>Warstwy kaskadowe wygrywaja z wojnami specyficznosci.</strong> Nadpisuj cokolwiek z pewnoscia — bez <code>!important</code>, bez trikow z kolejnoscia DOM.</li> <li><strong>Stylus wciaz jest dobry.</strong> Zwiezly, ekspresyjny i pozwala utrzymac biblioteke w ~3000 czytelnych linii.</li> <li><strong>Nudziarstwo to zaleta.</strong> Brak zaleznosci JS. Brak magii na etapie budowania. Brak lamianych zmian nazw. Klasy CSS, ktore robia dokladnie to, co mowia.</li> <li><strong>Dostosowalny w sekundy.</strong> Natywne CSS custom properties dla kolorow, odstepow, typografii i zaokraglen.</li> <li><strong>Utwardzony lancuch dostaw.</strong> Podpisane provenance npm. Przypiete aktualizacje Dependabot. CVE-2023-44270 poprawione przez overrides.</li> </ol> <h2>Wersjonowanie & semver</h2> <p>Skeletonic Stylus stosuje <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Poziom</th> <th>Kiedy</th> <th>Przyklad</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Usuniecie lub zmiana nazwy publicznej klasy, mixinu lub tokenu</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Dodanie nowego komponentu, mixinu lub tokenu</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Poprawki bledow, polerowanie a11y, wydajnosc, bezpieczenstwo</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Wszystkie publiczne nazwy klas, wszystkie CSS custom properties i wszystkie eksportowane mixiny Stylus sa czescia publicznego API.

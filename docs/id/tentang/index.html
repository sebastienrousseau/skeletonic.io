tertanam di setiap komponen, tidak pernah ditempelkan sebagai "tema".</li> <li><strong>Setiap byte penting.</strong> Satu stylesheet yang dikirimkan tidak boleh membengkakkan anggaran berat halaman. Batas 8 KB gzipped ditegakkan di CI.</li> <li><strong>Cascade layers mengalahkan perang spesifisitas.</strong> Timpa apa pun dengan percaya diri — tanpa <code>!important</code>, tanpa trik urutan DOM.</li> <li><strong>Stylus tetap bagus.</strong> Ringkas, ekspresif, dan memungkinkan pustaka tetap dalam ~3.000 baris yang mudah dibaca.</li> <li><strong>Membosankan itu fitur.</strong> Tanpa dependensi JS. Tanpa sihir build-time. Tanpa perubahan nama yang merusak. Kelas CSS yang melakukan persis seperti namanya.</li> <li><strong>Dapat disesuaikan dalam hitungan detik.</strong> CSS custom properties native untuk warna, spasi, tipografi, dan radius.</li> <li><strong>Rantai pasokan yang diperkuat.</strong> Provenance npm yang ditandatangani. Pembaruan Dependabot yang dikunci. CVE-2023-44270 dipatch melalui overrides.</li> </ol> <h2>Versioning & semver</h2> <p>Skeletonic Stylus mengikuti <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Level</th> <th>Kapan</th> <th>Contoh</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Menghapus atau mengganti nama kelas publik, mixin, atau token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Menambahkan komponen, mixin, atau token baru</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Perbaikan bug, penyempurnaan a11y, performa, keamanan</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Semua nama kelas publik, semua CSS custom properties, dan semua mixin Stylus yang diekspor adalah bagian dari API publik.

ogni componente, mai aggiunta come "tema" opzionale.</li> <li><strong>Ogni byte conta.</strong> Un singolo foglio di stile distribuito non deve sforare il budget di peso della pagina. Il limite di 8 KB gzipped e imposto nella CI.</li> <li><strong>I cascade layer battono le guerre di specificita.</strong> Sovrascrivi qualsiasi cosa con sicurezza — nessun <code>!important</code>, nessun trucco sull'ordine del DOM.</li> <li><strong>Stylus e ancora valido.</strong> Conciso, espressivo e permette di mantenere la libreria in ~3.000 righe leggibili.</li> <li><strong>La semplicita e una feature.</strong> Nessuna dipendenza JS. Nessuna magia in fase di build. Nessuna rinomina che rompe la compatibilita. Classi CSS che fanno esattamente quello che dicono.</li> <li><strong>Personalizzabile in pochi secondi.</strong> Proprieta CSS custom native per colori, spaziature, tipografia e raggi.</li> <li><strong>Supply chain blindata.</strong> Provenienza npm firmata. Aggiornamenti Dependabot bloccati. CVE-2023-44270 corretta tramite override.</li> </ol> <h2>Versionamento & semver</h2> <p>Skeletonic Stylus segue il <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Livello</th> <th>Quando</th> <th>Esempio</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Rimozione o rinomina di una classe pubblica, mixin o token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Aggiunta di un nuovo componente, mixin o token</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Correzioni di bug, miglioramenti a11y, performance, sicurezza</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Tutti i nomi di classe pubblici, tutte le proprieta CSS custom e tutti i mixin Stylus esportati fanno parte dell'API pubblica.

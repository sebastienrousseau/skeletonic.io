<div lang="en"><h2>In sintesi</h2> <blockquote> <p><strong>skeletonic.io non imposta cookie di tracciamento e non esegue tag di analisi di terze parti.</strong> Il sito e un insieme statico di HTML, CSS e un singolo file service-worker. Nessuna richiesta viene registrata oltre ai log di accesso standard di GitHub Pages.</p> </blockquote> <hr class="hr-text" data-content="Dettagli"> <h2>Quali dati vengono raccolti</h2> <ol> <li><strong>Log di accesso di GitHub Pages.</strong> Quando carichi una pagina, GitHub registra il tuo indirizzo IP, l'URL della richiesta e l'orario. Si applica l'informativa sulla privacy di GitHub — vedi <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">docs.github.com/en/site-policy</a>.</li> <li><strong>Il modulo di contatto.</strong> Se invii il modulo su <code>/it/contatti/</code>, i dati passano attraverso <a href="https://formspree.io">Formspree</a>, che li inoltra all'email del maintainer. Si applica l'informativa sulla privacy di Formspree.</li> <li><strong>Service worker.</strong> Lo script <code>sw.js</code> memorizza nella cache risposte HTML, CSS, JS e immagini <strong>localmente nel tuo browser</strong> cosi il sito funziona offline. Nulla viene inviato da nessuna parte.</li> </ol> <h2>Cosa <em>non</em> viene raccolto</h2> <ul> <li>Google Analytics, Plausible, Fathom o qualsiasi altro tag di analisi.</li> <li>Cookie di qualsiasi tipo. Il sito non ne imposta.</li> <li>Local storage o IndexedDB oltre alla cache del service worker.</li> <li>Fingerprinting, reti pubblicitarie o tracker di terze parti.</li> </ul> <h2>I tuoi diritti</h2> <p>Se hai usato il modulo di contatto e desideri che il tuo messaggio venga cancellato, inviami un'email dall'indirizzo con cui hai effettuato l'invio e lo eliminero entro 30 giorni.</p> <p><a href="/it/termini/">Leggi i termini →</a> · <a href="/it/contatti/">Contattaci →</a></p> </div>

the numbers honestly</h2> <ul> <li> <p><strong>Open Props</strong> and <strong>Shoelace <code>themes/light.css</code></strong> are token libraries, not component frameworks. They give you <code>--cl-*</code>-style design tokens; you still write every component yourself. Listing them as "smaller" is misleading without that context — they aren't solving the same problem as Skeletonic, Bootstrap, Bulma, or Pico.</p> </li> <li> <p><strong>Tailwind Play CDN</strong> (<code>cdn.tailwindcss.com</code>) is a JavaScript shim that compiles utility classes at runtime. The 407 KB raw / 123 KB gzip / 105 KB brotli is the <strong>JS</strong> bundle, not CSS. A production Tailwind v4 build is purged and typically ships well under 10 KB gzip — but only if you've added the Oxide build pipeline that Skeletonic was designed to avoid. <strong>If you want JS-free, no-toolchain CSS, the Tailwind Play CDN is the only Tailwind option, and it is the largest payload in this table by an order of magnitude.</strong></p> </li> <li> <p><strong>Bootstrap</strong> numbers above are CSS only. The full <code>bootstrap.bundle.min.js</code> (Popper + Bootstrap JS, required for modals / dropdowns / tooltips) adds <strong>≈ 81 KB gzip</strong> on top. Skeletonic ships <strong>zero</strong> JS.</p> </li> <li> <p><strong>Bulma</strong> ships everything by default. A modular Bulma build is much smaller, but again costs you a Sass pipeline.</p> </li> <li> <p><strong>Pico CSS</strong> is the closest no-build-step competitor at the same weight class. Pico is <em>classless</em> — semantic HTML only, no grid system, no utility classes, limited customisation surface. Skeletonic is class-based; different ergonomic trade-off, similar weight.</p> </li> <li> <p><strong>Skeletonic 2.0.0</strong> absorbs the v2.0.0 RTL refactor (95 logical-property declarations, 19 <code>[dir="rtl"]</code> overrides). The pre-RTL bundle was ≈ 7.5 KB gzip — that's the historical number you may see in older docs.</p> </li> </ul> <hr class="hr-text" data-content="Reproduce"> <h2>Reproduce in 30 seconds</h2> <pre><code

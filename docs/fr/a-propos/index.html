un « thème ».</li> <li><strong>Chaque octet compte.</strong> Une seule feuille de style livrée ne doit pas exploser votre budget de poids de page. Le plafond de 8 Ko gzippé est appliqué en CI.</li> <li><strong>Les couches de cascade battent les guerres de spécificité.</strong> Surcharger quoi que ce soit en confiance — pas de <code>!important</code>, pas d'astuces d'ordre DOM.</li> <li><strong>Stylus reste pertinent.</strong> Concis, expressif, et permet à la bibliothèque de tenir en ~3 000 lignes lisibles.</li> <li><strong>L'ennui est une fonctionnalité.</strong> Aucune dépendance JS. Aucune magie au build. Aucun renommage cassant. Des classes CSS qui font exactement ce qu'elles annoncent.</li> <li><strong>Personnalisable en quelques secondes.</strong> Propriétés personnalisées CSS natives pour les couleurs, l'espacement, la typographie et les rayons.</li> <li><strong>Chaîne d'approvisionnement renforcée.</strong> Provenance npm signée. Mises à jour Dependabot épinglées. CVE-2023-44270 corrigée via overrides.</li> </ol> <h2>Versionnement et semver</h2> <p>Skeletonic Stylus suit le <a href="https://semver.org">Versionnement Sémantique 2.0</a>.</p> <table> <thead> <tr> <th>Incrément</th> <th>Quand</th> <th>Exemple</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Majeur</strong></td> <td class="text-left">Suppression ou renommage d'une classe, mixin ou jeton public</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Mineur</strong></td> <td class="text-left">Ajout d'un nouveau composant, mixin ou jeton</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Corrections de bogues, polish a11y, performance, sécurité</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Tous les noms de classe publics, toutes les propriétés personnalisées CSS et tous les mixins Stylus exportés font partie de l'API publique.

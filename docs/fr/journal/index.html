<strong>focus-not-obscured</strong> avec scroll-margin pour les en-têtes collants.</li> </ul> <h3>Build et chaîne d'approvisionnement</h3> <ul> <li><strong>Couches de cascade</strong> — chaque bloc vit désormais dans <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.</li> <li><strong>SBOM CycloneDX</strong> généré dans le tarball npm.</li> <li><strong>Budgets <code>size-limit</code></strong> appliqués en CI : plafond de 8 Ko gzippé sur la feuille de style principale.</li> <li><strong>CVE-2023-44270</strong> (retour à la ligne postcss) corrigé via <code>pnpm.overrides</code>.</li> <li>Provenance et signature sur le workflow de publication npm (<code>--provenance --access public</code>).</li> <li>Suppression du plugin archivé <code>stylelint-a11y</code> de la configuration de lint.</li> </ul> <h3>Hygiène du dépôt et paquet consommateur</h3> <ul> <li>Suppression de l'ancien répertoire <code>package/</code> ; <code>dist/</code> est désormais la source unique de vérité pour les consommateurs.</li> <li>README réécrit pour refléter les chemins d'installation v2.0.0.</li> <li><code>dist/</code> est commité ; <code>debug/</code> est généré et gitignored.</li> <li>Nouveau <code>.github/workflows/npm-publish.yml</code> déclenché par tag.</li> </ul> <h3>Correctifs de bogues (P0)</h3> <ul>

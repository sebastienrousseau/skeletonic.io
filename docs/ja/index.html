Skeletonic Stylus

アクセシブルな CSS を gzip圧縮で8 KB未満 で実現。WCAG 2.2 対応。 カスケードレイヤー採用。JavaScript 不要。どのページにもすぐに導入できます。

pnpm add @sebastienrousseau/skeletonic-stylus@2.0.0

Skeletonic の構成

ライブラリへの6つの入口。必要なものを選んでください。

はじめに

一度インストールするだけ。数秒でテーマ設定。CDN から Stylus パイプラインまで対応。

コンポーネント

ボタン、アラート、バッジ、カード、フォーム、ヘッダー — すべてのスニペットがコピー＆ペーストで使えます。

パレット

Material、Tachyons、ウェブセーフの各カラーシステム。そのまま準拠しています。

アニメーション

バウンス、フェード、パルス、シェイク、バニッシュ、ズーム — すべて prefers-reduced-motion で制御されます。

アクセシビリティ

フォーカスリング。AAコントラスト。スキップリンク。モーション軽減。ダークモード。すべて組み込み済み。

セキュリティ

CycloneDX SBOM。npm プロベナンス。固定された依存関係。CVE パッチ適用済み。

要約

skeletonic.io はトラッキング Cookie を設定せず、サードパーティの分析タグも実行しません。 このサイトは HTML、CSS、および単一のサービスワーカーファイルの静的セットです。あなたのリクエストは、標準的な GitHub Pages アクセスログ以外には記録されません。

収集されるデータ

  1. GitHub Pages アクセスログ。 ページを読み込むと、GitHub はあなたの IP アドレス、リクエスト URL、時刻を記録します。GitHub のプライバシーポリシーが適用されます — docs.github.com/en/site-policy をご覧ください。
  2. お問い合わせフォーム。 /ja/otoiawase/ でフォームを送信すると、データは Formspree を通じてメンテナーのメールに転送されます。Formspree のプライバシーポリシーが適用されます。
  3. サービスワーカー。 sw.js スクリプトは、サイトがオフラインで動作するよう HTML、CSS、JS、画像のレスポンスを ブラウザにローカルで キャッシュします。どこにもデータは送信されません。

収集 されない データ

  • Google Analytics、Plausible、Fathom、その他いかなる分析タグも使用しません。
  • いかなる種類の Cookie も設定しません。
  • サービスワーカーキャッシュ以外の Local Storage や IndexedDB は使用しません。
  • フィンガープリンティング、広告ネットワーク、サードパーティトラッカーは一切ありません。

あなたの権利

お問い合わせフォームを使用し、メッセージの削除を希望される場合は、送信時のメールアドレスからメールをお送りください。30日以内に削除いたします。

Ninguna solicitud que realices se registra mas alla de los registros de acceso estandar de GitHub Pages.</p> </blockquote> <hr class="hr-text" data-content="Detalles"> <h2>Que datos se recopilan</h2> <ol> <li><strong>Registros de acceso de GitHub Pages.</strong> Cuando cargas cualquier pagina, GitHub registra tu direccion IP, la URL de la solicitud y la hora. Se aplica la politica de privacidad de GitHub — consulta <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">docs.github.com/en/site-policy</a>.</li> <li><strong>El formulario de contacto.</strong> Si envias el formulario en <code>/es/contacto/</code>, los datos se transmiten a traves de <a href="https://formspree.io">Formspree</a>, que los reenvia al correo del mantenedor. Se aplica la politica de privacidad de Formspree.</li> <li><strong>Service worker.</strong> El script <code>sw.js</code> almacena en cache las respuestas HTML, CSS, JS e imagenes <strong>localmente en tu navegador</strong> para que el sitio funcione sin conexion. No se envia nada a ningun servidor.</li> </ol> <h2>Que <em>no</em> se recopila</h2> <ul> <li>Google Analytics, Plausible, Fathom, ni ningun otro tag de analitica.</li> <li>Cookies de ningun tipo.

opcional.</li> <li><strong>Cada byte cuenta.</strong> Una sola hoja de estilos no deberia exceder tu presupuesto de peso de pagina. El limite de 8 KB gzipped se aplica en CI.</li> <li><strong>Las capas de cascada superan las guerras de especificidad.</strong> Sobrescribe cualquier cosa con confianza — sin <code>!important</code>, sin trucos de orden DOM.</li> <li><strong>Stylus sigue siendo bueno.</strong> Conciso, expresivo, y permite que la biblioteca se mantenga en ~3.000 lineas legibles.</li> <li><strong>Lo aburrido es una ventaja.</strong> Sin dependencias JS. Sin magia en tiempo de compilacion. Sin renombramientos disruptivos. Clases CSS que hacen exactamente lo que dicen.</li> <li><strong>Personalizable en segundos.</strong> Propiedades personalizadas CSS nativas para colores, espaciado, tipografia y radios.</li> <li><strong>Cadena de suministro reforzada.</strong> Procedencia npm firmada. Actualizaciones Dependabot fijadas. CVE-2023-44270 parcheado via overrides.</li> </ol> <h2>Versionado y semver</h2> <p>Skeletonic Stylus sigue <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Incremento</th> <th>Cuando</th> <th>Ejemplo</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Eliminar o renombrar una clase publica, mixin o token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Anadir un nuevo componente, mixin o token</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Correcciones de errores, mejoras de a11y, rendimiento, seguridad</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Todos los nombres de clases publicas, todas las propiedades personalizadas CSS y todos los mixins Stylus exportados son parte de la API publica.

suministro, higiene del repositorio.</p> <h3>Accesibilidad (WCAG 2.2)</h3> <ul> <li><strong><code>$primary</code> oscurecido</strong> a <code>hsl(210, 100%, 42%)</code> para contraste AA contra texto blanco en botones / insignias / enlaces.</li> <li><strong><code>$secondary</code> oscurecido</strong> a <code>hsl(195, 100%, 33%)</code>.</li> <li>Se anadieron <strong>anillos focus-visible</strong> en cada elemento interactivo.</li> <li>Se anadio envoltorio <strong><code>@media (prefers-reduced-motion)</code></strong> alrededor del modulo de animaciones.</li> <li>Se anadio intercambio de tokens con <strong><code>prefers-color-scheme: dark</code></strong>.</li> <li>Se anadio mixin <strong>target-size(24px)</strong> para satisfacer WCAG 2.2 SC 2.5.8.</li> <li>Se anadieron helpers <strong>focus-not-obscured</strong> de scroll-margin para encabezados fijos.</li> </ul> <h3>Build y cadena de suministro</h3> <ul> <li><strong>Capas de cascada</strong> — cada bloque ahora vive en <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.</li> <li><strong>SBOM CycloneDX</strong> generado como parte del tarball npm.</li> <li><strong>Presupuestos <code>size-limit</code></strong> aplicados en CI: limite de 8 KB gzipped en la hoja de estilos principal.</li> <li><strong>CVE-2023-44270</strong> (retorno de linea en postcss) parcheado via <code>pnpm.overrides</code>.</li> <li>Procedencia + firma en el workflow de publicacion npm (<code>--provenance --access public</code>).</li> <li>Se elimino el plugin archivado <code>stylelint-a11y</code> de la configuracion de lint.</li> </ul> <h3>Higiene del repositorio y paquete para consumidores</h3> <ul> <li>Se elimino el directorio legacy <code>package/</code>; <code>dist/</code> es ahora la unica fuente de verdad para los consumidores.</li> <li>README reescrito para reflejar las rutas de instalacion de v2.0.0.</li> <li><code>dist/</code> se commitea; <code>debug/</code> se genera y se incluye en gitignore.</li> <li>Nuevo <code>.github/workflows/npm-publish.yml</code> dirigido por tags.</li> </ul> <h3>Correcciones de errores (P0)</h3> <ul> <li><strong>Regresion del selector padre <code>row $:after</code></strong> — se reemplazo el <code>$</code> erroneo por <code>&</code> en <code>src/stylus/components/_grid.styl</code>.</li> <li><strong><code>.alternate</code></strong> aplicaba por error <code>animation-direction: reverse</code> en lugar de <code>alternate</code>.</li> <li><strong>Namespacing de <code>.alert-*</code></strong> — <code>.alert.success</code> → <code>.alert.alert-success</code> para evitar colisiones con clases de estado.</li> </ul> <p><a

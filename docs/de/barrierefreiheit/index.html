<p>Fügen Sie dieses Element <strong>als erstes innerhalb von <code><body></code></strong> ein:</p> <pre><code class="language-html"><pre style="background-color:#0d1117;"> <span <p>Die Klasse ist <strong>nicht</strong> im Kern-Stylesheet enthalten (die Seitengröße bleibt also unverändert); es handelt sich um ein 4-Zeilen-Snippet, das Sie selbst erstellen oder über das mitgelieferte <code>skip-link()</code>-Mixin einbinden.

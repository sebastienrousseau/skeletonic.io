<li><strong><code>$primary</code> 加深</strong>至 <code>hsl(210, 100%, 42%)</code>，使按鈕/徽章/連結中的白色文字達到 AA 對比度。</li> <li><strong><code>$secondary</code> 加深</strong>至 <code>hsl(195, 100%, 33%)</code>。</li> <li>為每個互動元素添加 <strong>focus-visible</strong> 焦點環。</li> <li>在動畫模組中添加 <strong><code>@media (prefers-reduced-motion)</code></strong> 包裹。</li> <li>添加 <strong><code>prefers-color-scheme: dark</code></strong> token 切換。</li> <li>添加 <strong>target-size(24px)</strong> mixin 以滿足 WCAG 2.2 SC 2.5.8。</li> <li>添加 <strong>focus-not-obscured</strong> scroll-margin 輔助，用於固定頁首。</li> </ul> <h3>建置與供應鏈</h3> <ul> <li><strong>級聯層</strong> — 每個區塊現在都位於 <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code> 中。</li> <li><strong>CycloneDX SBOM</strong> 作為 npm 壓縮檔的一部分生成。</li> <li><strong><code>size-limit</code> 預算</strong>在 CI 中強制執行：核心樣式表 8 KB gzip 上限。</li> <li><strong>CVE-2023-44270</strong>（postcss 換行解析）透過 <code>pnpm.overrides</code> 修補。</li> <li>npm 發佈工作流程啟用來源驗證與簽署（<code>--provenance --access public</code>）。</li> <li>從 lint 設定中移除已歸檔的 <code>stylelint-a11y</code> 外掛。</li> </ul> <h3>儲存庫整理與消費者套件</h3> <ul> <li>移除舊版 <code>package/</code> <code>.github/workflows/npm-publish.yml</code> 由標籤驅動。</li> </ul> <h3>錯誤修正（P0）</h3> <ul> <li><strong><code>row $:after</code> 父選擇器回歸</strong> — 將 <code>src/stylus/components/_grid.styl</code> 中的雜散

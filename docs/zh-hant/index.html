Skeletonic Stylus

Skeletonic Stylus 是一個輕量級、模組化的 Stylus CSS 函式庫——符合 WCAG 2.2 標準、採用級聯層架構、gzip 後約 7.5 KB——旨在簡化現代 Web UI 開發。

pnpm add @sebastienrousseau/skeletonic-stylus

無障礙 CSS，gzip 後不到 8 KB。符合 WCAG 2.2 標準。 級聯層架構。零 JavaScript。即插即用。

pnpm add @sebastienrousseau/skeletonic-stylus@1.1.7

Skeletonic 架構解析

六條路徑通向函式庫的核心，按需選用。

快速入門

一次安裝，秒級主題定製。從 CDN 到 Stylus 建置管線一應俱全。

組件

按鈕、提示框、徽章、卡片、表單、頁首——每段程式碼均可直接複製貼上。

色板

Material、Tachyons 與 Web 安全配色方案，開箱即符合規範。

動畫

彈跳、淡入、脈衝、抖動、消失和縮放——均受 prefers-reduced-motion 控制。

無障礙

焦點環、AA 對比度、跳轉連結、減弱動效、深色模式，全部內建。

安全

CycloneDX SBOM、npm 來源驗證、依賴鎖定、CVE 已修補。

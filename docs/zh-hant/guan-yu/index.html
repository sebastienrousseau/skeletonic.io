<h2>原則</h2> <ol> <li><strong>無障礙是底線，而非天花板。</strong> WCAG 2.2 合規性內建於每個組件，絕非後期加裝的「主題」。</li> <li><strong>每個位元組都很重要。</strong> 單一樣式表不應超出頁面載重預算。8 KB gzip 上限在 CI 中強制執行。</li> <li><strong>級聯層勝過特異性之戰。</strong> 自信地覆寫任何樣式——無需 <code>!important</code>，無需 DOM 順序技巧。</li> <li><strong>Stylus 依然出色。</strong> 簡潔、富表現力，讓函式庫維持在約 3,000 行可讀程式碼。</li> <li><strong>無聊即特色。</strong> 無 JS 依賴、無建置時魔法、無破壞性重新命名。CSS 類別名稱所見即所得。</li> <li><strong>秒級主題定製。</strong> 原生 CSS 自訂屬性涵蓋色彩、間距、排版與圓角。</li> <li><strong>供應鏈強化。</strong> 簽名的 npm 來源驗證、鎖定的 Dependabot 更新、透過 overrides 修補 CVE-2023-44270。</li> </ol> <h2>版本管理與語意化版本</h2> <p>Skeletonic

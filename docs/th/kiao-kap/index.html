<h2>สรุปสั้น ๆ</h2> <p><strong>Skeletonic Stylus</strong> เป็นไลบรารี CSS แบบ <a href="https://stylus-lang.com">Stylus</a> โอเพนซอร์ส สำหรับการจัดสไตล์ UI ที่เข้าถึงได้ รวดเร็ว และเป็นโมดูล</p> <p>เริ่มต้นในปี 2018 ในฐานะการทดลองส่วนตัวเกี่ยวกับ <strong>การส่ง CSS น้อยลง</strong> โดยไม่สูญเสียความสะดวกในการใช้งานของไลบรารีส่วนประกอบจริง ผ่านมาแปดปี เป้าหมายยังคงเหมือนเดิม</p>

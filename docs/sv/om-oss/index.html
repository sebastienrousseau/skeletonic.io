taket.</strong> WCAG 2.2-uppfyllnad ar inbyggt i varje komponent, inte paklistrat som ett "tema".</li> <li><strong>Varje byte raknas.</strong> Ett enda utlevererat stylesheet ska inte spranga sidviktsbudgeten. Taket pa 8 KB gzippat tillapas i CI.</li> <li><strong>Cascade layers slar specificitetskrig.</strong> Overskriv vad som helst med sjalvfortroende — inget <code>!important</code>, inga DOM-ordningstrick.</li> <li><strong>Stylus ar fortfarande bra.</strong> Koncist, uttrycksfullt och haller biblioteket pa ~3 000 lasbara rader.</li> <li><strong>Tradigt ar en funktion.</strong> Inga JS-beroenden. Ingen magi vid byggtid. Inga brotande namnbyten. CSS-klasser som gor exakt det deras namn sager.</li> <li><strong>Anpassningsbart pa sekunder.</strong> Nativa CSS custom properties for farger, avstand, typografi och radier.</li> <li><strong>Hardad leveranskedja.</strong> Signerad npm-proveniens. Lasta Dependabot-uppdateringar. CVE-2023-44270 patchad via overrides.</li> </ol> <h2>Versionshantering & semver</h2> <p>Skeletonic Stylus foljer <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Niva</th> <th>Nar</th> <th>Exempel</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Borttagning eller namnbyte av en offentlig klass, mixin eller token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Tillagg av en ny komponent, mixin eller token</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Buggfixar, a11y-finjustering, prestanda, sakerhet</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Alla offentliga klassnamn, alla CSS custom properties och alla exporterade Stylus-mixins ar del av det offentliga API:et.

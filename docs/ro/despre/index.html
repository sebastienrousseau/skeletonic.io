</table></div> <h2>Principii</h2> <ol> <li><strong>Accesibilitatea este baza, nu opționalul.</strong> Conformitatea WCAG 2.2 este integrată în fiecare componentă, nu adăugată ulterior ca „temă".</li> <li><strong>Fiecare octet contează.</strong> Un singur stylesheet livrat nu trebuie să depășească bugetul de greutate al paginii. Limita de 8 KB gzipped este impusă în CI.</li> <li><strong>Cascade layers bat războaiele de specificitate.</strong> Suprascrie orice cu încredere — fără <code>!important</code>, fără trucuri cu ordinea DOM.</li> <li><strong>Stylus este încă o alegere excelentă.</strong> Concis, expresiv și permite bibliotecii să se mențină în ~3.000 de linii lizibile.</li> <li><strong>Previzibilul este o virtute.</strong> Fără dependențe JS. Fără magie la build. Fără redenumiri disruptive. Clase CSS care fac exact ceea ce spune numele lor.</li> <li><strong>Personalizabil în secunde.</strong> Proprietăți CSS native personalizate pentru culori, spațiere, tipografie și raze.</li> <li><strong>Lanț de aprovizionare securizat.</strong> Proveniență npm semnată. Actualizări Dependabot fixate. CVE-2023-44270 rezolvat prin overrides.</li> </ol> <h2>Versionare & semver</h2> <p>Skeletonic Stylus urmează <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Nivel</th> <th>Când</th> <th>Exemplu</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Eliminarea sau redenumirea unei clase publice, a unui mixin sau token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Adăugarea unei componente, a unui mixin sau token nou</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Remedieri de erori, rafinări a11y, performanță, securitate</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Toate numele de clase publice, toate proprietățile CSS personalizate și toate mixin-urile Stylus exportate fac parte din API-ul public.

للمكتبة البقاء في ~3,000 سطر قابل للقراءة.</li> <li><strong>البساطة ميزة.</strong> بدون تبعيات JS. بدون سحر وقت البناء. بدون إعادة تسمية مُعطّلة. فئات CSS تفعل بالضبط ما يقوله اسمها.</li>

componente, nunca adicionada como um "tema".</li> <li><strong>Cada byte importa.</strong> Uma unica folha de estilos entregue nao deve estourar seu orcamento de peso de pagina. O limite de 8 KB gzipped e aplicado no CI.</li> <li><strong>Cascade layers vencem guerras de especificidade.</strong> Sobrescreva qualquer coisa com confianca — sem <code>!important</code>, sem truques de ordem no DOM.</li> <li><strong>Stylus continua sendo uma otima opcao.</strong> Conciso, expressivo e permite manter a biblioteca em ~3.000 linhas legiveis.</li> <li><strong>Chato e um recurso.</strong> Sem dependencias JS. Sem magica em tempo de build. Sem renomeacoes que quebram compatibilidade. Classes CSS que fazem exatamente o que dizem.</li> <li><strong>Personalizavel em segundos.</strong> CSS custom properties nativas para cores, espacamento, tipografia e bordas arredondadas.</li> <li><strong>Cadeia de suprimentos fortalecida.</strong> Procedencia npm assinada. Atualizacoes Dependabot fixadas. CVE-2023-44270 corrigido via overrides.</li> </ol> <h2>Versionamento & semver</h2> <p>Skeletonic Stylus segue o <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Nivel</th> <th>Quando</th> <th>Exemplo</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Remocao ou renomeacao de uma classe publica, mixin ou token</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Adicao de um novo componente, mixin ou token</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Correcoes de bugs, ajustes de a11y, performance, seguranca</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Todos os nomes de classes publicas, todas as CSS custom properties e todos os mixins Stylus exportados fazem parte da API publica.

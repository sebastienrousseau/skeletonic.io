<div lang="en"><h2>Resumo</h2> <blockquote> <p><strong>skeletonic.io nao define cookies de rastreamento e nao executa nenhuma tag de analytics de terceiros.</strong> O site e um conjunto estatico de HTML, CSS e um unico arquivo de service worker. Nenhuma requisicao sua e registrada alem dos logs de acesso padrao do GitHub Pages.</p> </blockquote> <hr class="hr-text" data-content="Detalhes"> <h2>Quais dados sao coletados</h2> <ol> <li><strong>Logs de acesso do GitHub Pages.</strong> Quando voce carrega qualquer pagina, o GitHub registra seu endereco IP, a URL da requisicao e o horario. A politica de privacidade do GitHub se aplica — consulte <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">docs.github.com/en/site-policy</a>.</li> <li><strong>O formulario de contato.</strong> Se voce enviar o formulario em <code>/pt-br/contato/</code>, os dados passam pelo <a href="https://formspree.io">Formspree</a>, que encaminha para o email do mantenedor. A politica de privacidade do Formspree se aplica.</li> <li><strong>Service worker.</strong> O script <code>sw.js</code> armazena em cache respostas de HTML, CSS, JS e imagens <strong>localmente no seu navegador</strong> para que o site funcione offline. Nada e enviado para lugar algum.</li> </ol> <h2>O que <em>nao</em> e coletado</h2> <ul> <li>Google Analytics, Plausible, Fathom ou qualquer outra tag de analytics.</li> <li>Cookies de qualquer tipo. O site nao define nenhum.</li> <li>Local storage ou IndexedDB alem do cache do service worker.</li> <li>Fingerprinting, redes de anuncios ou rastreadores de terceiros.</li> </ul> <h2>Seus direitos</h2> <p>Se voce usou o formulario de contato e gostaria que sua mensagem fosse excluida, envie um email do mesmo endereco que utilizou para o envio e eu farei a exclusao em ate 30 dias.</p> <p><a href="/pt-br/termos/">Leia os termos →</a> · <a href="/pt-br/contato/">Entre em contato →</a></p> </div>

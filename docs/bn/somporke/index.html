সংক্ষেপে

Skeletonic Stylus একটি ওপেন-সোর্স Stylus CSS লাইব্রেরি, অ্যাক্সেসিবল, দ্রুত ও মডুলার UI স্টাইলিংয়ের জন্য।

২০১৮ সালে কম CSS শিপ করার ব্যক্তিগত পরীক্ষা-নিরীক্ষা হিসেবে জন্ম নেয়া, একটি প্রকৃত কম্পোনেন্ট লাইব্রেরির সুবিধা ছাড়া নয়। আট বছর পরও লক্ষ্য অপরিবর্তিত।

এটি আপনাকে যা দেয়

বজ্রগতিতে দ্রুত

মিনিটের মধ্যে রেসপন্সিভ ইন্টারফেস ডিজাইন ও কাস্টমাইজ করুন। নেটিভ CSS ভেরিয়েবল, পূর্বনির্ধারিত ক্লাস, প্রতিটি সেমান্টিক HTML এলিমেন্ট কভার করা ১২-কলাম গ্রিড।

হালকা

~৭.৫ KB gzipped। পেজ দ্রুত লোড হয়। প্রতিটি অপরিহার্য বিল্ডিং ব্লক অন্তর্ভুক্ত।

রেসপন্সিভ ডিজাইন

ডেস্কটপ ও মোবাইলের জন্য তৈরি। লেআউট যেকোনো ডিভাইসে মানিয়ে নেয়। টাচ-অপ্টিমাইজড, সর্বত্র সেমান্টিক HTML।

প্রবেশাধিকার

WCAG 2.2 অন্তর্নির্মিত: focus-visible রিং, AA কনট্রাস্ট, skip-link সহায়ক, কীবোর্ড-বান্ধব কম্পোনেন্ট, reduced-motion সমর্থন — কোনো অতিরিক্ত স্টাইলশিট নেই, কোনো aria-* বয়লারপ্লেট নেই।

কম্পোনেন্ট লাইব্রেরি

মডুলার CSS কম্পোনেন্ট ও Stylus মিক্সিন। বাটন, ফর্ম, কার্ড, অ্যালার্ট, ব্যাজ, প্যালেট ও অ্যানিমেশন — পরিচ্ছন্ন, মডুলার, ড্রপ ইন করার জন্য প্রস্তুত।

বিনামূল্যে ও ওপেন সোর্স

Sebastien Rousseau দ্বারা ডিজাইনকৃত, নির্মিত ও রক্ষণাবেক্ষিত। MIT বা Apache 2.0 দ্বৈত লাইসেন্সপ্রাপ্ত। কোনো ফি নেই, কোনো লাইসেন্সিং খরচ নেই, বাণিজ্যিক ব্যবহারেও।

তুলনামূলক বিশ্লেষণ

একটি সেলফ-হোস্টেড স্টাইলশিট টাইপোগ্রাফি, বাটন, ফর্ম, কার্ড, টেবিল, প্যালেট, অ্যানিমেশন এবং ইউটিলিটি ক্লাস কভার করে। কোনো জাভাস্ক্রিপ্ট নেই। কোনো বিল্ড স্টেপ লাগে না। Bootstrap, Tailwind বা Bulma-র উপর কোনো নির্ভরতা নেই।

নীতিমালা

  1. প্রবেশাধিকার মেঝে, সিলিং নয়। WCAG 2.2 সামঞ্জস্য প্রতিটি কম্পোনেন্টে অন্তর্নির্মিত, কখনো "থিম" হিসেবে আলাদা করে যোগ করা নয়।
  2. বাইট গুরুত্বপূর্ণ। একটি শিপ করা স্টাইলশিট আপনার পেজ-ওয়েট বাজেট নষ্ট করা উচিত নয়। ৮ KB gzipped সীমা CI-তে বাধ্যতামূলক।
  3. Cascade layers specificity যুদ্ধকে পরাজিত করে। আত্মবিশ্বাসের সাথে যেকোনো কিছু ওভাররাইড করুন — কোনো !important নেই, কোনো DOM-order কৌশল নেই।
  4. Stylus এখনও চমৎকার। সংক্ষিপ্ত, অভিব্যক্তিপূর্ণ, এবং লাইব্রেরিকে ~৩,০০০ পাঠযোগ্য লাইনে রাখতে সক্ষম।
  5. বিরক্তিকর হওয়াটাই বৈশিষ্ট্য। কোনো JS নির্ভরতা নেই। কোনো বিল্ড-টাইম জাদু নেই। কোনো ব্রেকিং রিনেম নেই। CSS ক্লাস যা ঠিক তা-ই করে যা বলে।
  6. সেকেন্ডে থিম পরিবর্তনযোগ্য। রঙ, স্পেসিং, টাইপ ও রেডিয়ায়ের জন্য নেটিভ CSS কাস্টম প্রপার্টি।
  7. সাপ্লাই-চেইন সুরক্ষিত। স্বাক্ষরিত npm provenance। পিন করা Dependabot আপডেট। CVE-2023-44270 overrides দিয়ে প্যাচড।

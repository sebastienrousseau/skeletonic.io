CycloneDX SBOM

প্রতিটি প্রকাশিত tarball-এ dist/sbom.json-এ একটি CycloneDX SBOM অন্তর্ভুক্ত। আপনি সদ্য ইনস্টল করা প্যাকেজ যাচাই করতে পারেন:

pnpm add @sebastienrousseau/skeletonic-stylus@2.0.0
jq '.metadata.component.version' \
  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json
# → "2.0.0"

SBOM প্রকাশ ওয়ার্কফ্লোতে cyclonedx-npm দিয়ে তৈরি হয়।

npm provenance

প্রকাশিত আর্টিফ্যাক্ট npm package provenance ব্যবহার করে স্বাক্ষরিত।

ইনস্টলের পর এটি যাচাই করতে পারেন:

npm view @sebastienrousseau/skeletonic-stylus@2.0.0 --json | \
  jq '.dist."npm-signature"'

স্বাক্ষরিত attestation tarball-কে সেই সঠিক GitHub Actions রানের সাথে সংযুক্ত করে যেটি এটি তৈরি করেছে।

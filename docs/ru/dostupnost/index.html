style="background-color:#0d1117;"> <span style="color:#c0c5ce;"><</span><span style="color:#bf616a;">a </span><span style="color:#d08770;">href</span><span style="color:#c0c5ce;">="</span><span style="color:#a3be8c;">#main-content</span><span style="color:#c0c5ce;">" </span><span style="color:#d08770;">class</span><span style="color:#c0c5ce;">="</span><span style="color:#a3be8c;">skip-link</span><span style="color:#c0c5ce;">">Перейти к основному содержимому</</span><span style="color:#bf616a;">a</span><span style="color:#c0c5ce;">> </span></pre> </code></pre> <p>Класс <strong>не входит</strong> в основной файл стилей (поэтому размер страницы не увеличивается); это 4-строчный фрагмент, который вы создаёте самостоятельно или используете встроенный миксин <code>skip-link()</code>. Этот сайт использует его — сфокусируйте страницу и нажмите Tab, чтобы увидеть его в левом верхнем углу.</p> <hr class="hr-text" data-content="Проверка"> <h2>Проверка ваших страниц</h2> <p>Библиотека поставляет скрипт <code>a11y-test.mjs</code> в каталоге <code>scripts/</code>, который запускает <a href="https://github.com/dequelabs/axe-core">axe-core</a> для каждого указанного URL.</p> <pre><code class="language-bash"><pre style="background-color:#0d1117;"> <span style="color:#8fa1b3;">node</span><span style="color:#c0c5ce;"> scripts/a11y-test.mjs https://example.com </span></pre> </code></pre> <p>CI запускает этот скрипт для демонстрационной страницы <code>dist/index.html</code> при каждом push.</p> <p><a href="/ru/zhurnal-izmeneniy/">Читать о релизе v2.0.0 →</a> · <a href="/ru/bezopasnost/">Страница безопасности →</a></p> </div>

<code>pnpm.overrides</code>.</li> <li>Провенанс + подписание в процессе npm-публикации (<code>--provenance --access public</code>).</li> <li>Удалён архивированный плагин <code>stylelint-a11y</code> из конфигурации линтинга.</li> </ul> <h3>Гигиена репозитория и потребительский пакет</h3> <ul> <li>Устаревший каталог <code>package/</code> удалён; <code>dist/</code> теперь единственный источник для

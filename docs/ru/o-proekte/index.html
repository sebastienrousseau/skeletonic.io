встроено в каждый компонент, а не добавлено как отдельная «тема».</li> <li><strong>Каждый байт на счету.</strong> Один файл стилей не должен раздувать бюджет страницы. Лимит в 8 КБ gzip контролируется в CI.</li> <li><strong>Каскадные слои побеждают войны специфичности.</strong> Переопределяйте что угодно с уверенностью — без <code>!important</code>, без трюков с порядком DOM.</li> <li><strong>Stylus по-прежнему хорош.</strong> Лаконичный, выразительный, позволяет уместить библиотеку в ~3 000 читаемых строк.</li> <li><strong>Скучное — это преимущество.</strong> Без JS-зависимостей. Без магии на этапе сборки. Без ломающих переименований. CSS-классы делают именно то, что говорит их название.</li> <li><strong>Настройка за секунды.</strong> Нативные CSS Custom Properties для цветов, отступов, типографики и радиусов.</li> <li><strong>Защищённая цепочка поставок.</strong> Подписанный npm-провенанс. Закреплённые обновления Dependabot. CVE-2023-44270 исправлена через overrides.</li> </ol> <h2>Версионирование и semver</h2> <p>Skeletonic Stylus следует <a href="https://semver.org">Semantic Versioning 2.0</a>.</p> <table> <thead> <tr> <th>Уровень</th> <th>Когда</th> <th>Пример</th> </tr> </thead> <tbody> <tr> <td class="text-left"><strong>Major</strong></td> <td class="text-left">Удаление или переименование публичного класса, миксина или токена</td> <td class="text-left">1.x → 2.0</td> </tr> <tr> <td class="text-left"><strong>Minor</strong></td> <td class="text-left">Добавление нового компонента, миксина или токена</td> <td class="text-left">1.1 → 1.2</td> </tr> <tr> <td class="text-left"><strong>Patch</strong></td> <td class="text-left">Исправление ошибок, доработка a11y, производительность, безопасность</td> <td class="text-left">1.1.6 → 2.0.0</td> </tr> </tbody> </table> <p>Все публичные имена классов, все CSS Custom Properties и все экспортируемые Stylus-миксины являются частью публичного API.
